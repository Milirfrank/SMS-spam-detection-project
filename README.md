SMS Spam Detection Project:
About:
This project detects whether an SMS message is Spam or Not Spam using Machine Learning.

Objective:
To classify SMS messages and identify unwanted or suspicious messages.

Technologies Used:
Python
Google Colab
Jupyter Notebook
Machine Learning

Project File:
sms_spam.ipynb – Contains the project code and implementation.

How to Run:
Open the notebook in Google Colab.
Run the code cells in order.
Enter an SMS message to check whether it is Spam or Not Spam.

Conclusion:
This project helps identify spam messages and supports safer SMS communication.
